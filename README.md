# Pós-graduação — Engenharia de Software em IA Aplicada

Repositório de estudos, anotações e exercícios práticos realizados durante a pós-graduação em **Engenharia de Software em IA Aplicada**.

## Organização

O conteúdo é separado por **disciplina** e, dentro de cada disciplina, por **módulo**. Os diretórios serão preenchidos conforme o avanço nas aulas.

### 01 — Fundamentos de IA e LLMs para Programadores

Disciplina em andamento.

- [Módulo 01](01-fundamentos-ia-llms/modulo-01/README.md)
- [Módulo 02 — Machine Learning, Deep Learning e IA](01-fundamentos-ia-llms/modulo-02/README.md)
- Módulos 03 a 10: organização a preencher conforme as aulas.

## Objetivo

Registrar aprendizados, testar conceitos na prática e construir uma trilha de estudos que conecte **engenharia de software**, **qualidade de software** e **inteligência artificial**.
